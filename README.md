# Lodge Billing Lab (Java + Gradle)

Easiest (any JDK 17+, including Java 27, no Gradle needed):
  Windows:    double-click run.bat   (or type run.bat in a terminal)
  Mac/Linux:  ./run.sh

With Gradle (Gradle itself must run on Java 17 to 26; Java 27 is not supported by Gradle yet):
  gradle run
  gradle selfCheck

Practice logins (change before real use):
  admin      / admin123   (can delete bills)
  reception  / lodge123   (cannot delete bills)

Date format for reservations: yyyy-mm-dd
